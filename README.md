# Sistema Bancário 💰

Este projeto é uma simulação de um sistema bancário desenvolvido para praticar conceitos de lógica de programação e fluxos de decisão. O programa permite que o usuário realize operações básicas como depósitos, saques e visualização de extrato, além do cadastro de usuários.



## 🚀 Funcionalidades

O sistema conta com as seguintes operações:

* **Depósito:** Permite adicionar valores positivos à conta. Todas as transações são registradas no histórico.
* **Saque:** Permite retirar valores respeitando as regras de negócio:
    * Limite de 3 saques diários.
    * Valor máximo de R$ 500,00 por saque.
    * Bloqueio caso não haja saldo suficiente.
* **Extrato:** Lista todos os depósitos e saques realizados, exibindo o saldo atual no final.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Lógica:** Estruturas de repetição, condicionais, formatação de strings e dicionários.
